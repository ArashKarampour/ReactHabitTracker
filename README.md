# Habit Tracker Application

Habit Tracker is a simple web application built with React, TypeScript, and Vite. It allows users to track their daily habits and monitor their progress over time.

![HabbitTracker](<Habittracker.png>)

Initially, the application was created as a personal project to help me stay consistent with my daily habits. However, I decided to share it with the community in case it can be useful to others.

## Features
- Add and delete habits
- Mark habits as completed for each day
- View progress over time with a simple calendar view
